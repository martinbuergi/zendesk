# bl-hero

Custom **hero** block. Purpose: listing-hero-with-featured-stories.

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: lead story row (image | linked title + text), picks head row (h1 + h2), one row per pick (image | linked title), subscribe row (heading, text, placeholder, button label, hint).
