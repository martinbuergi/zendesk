# bl-latest

Custom **cards** block. Purpose: latest-stories-grid.

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: title row, then one row per card: image | linked title + description (+ optional tag links), then a pagination list row.
