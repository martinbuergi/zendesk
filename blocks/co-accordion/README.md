# co-accordion

Custom **accordion** block. Purpose: headed-accordion-with-data-tables.

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: item row (h3 title | optional panel prose), then rows of label (h4) | text for the item table, optional one-cell prose rows.
