# fm-form

Custom **form** block. Purpose: lead-capture-form.

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: one row per field: label (+ hint) | type + flags | field name | options list; then consent text row and submit label row.

## Supported variations

| Variation | Option class |
| --- | --- |
| Hidden | `hidden` |
| Login | `login` |
| Modal | `modal` |
| Instapage | `instapage` |
| Teaser | `teaser` |
| Halves | `halves` |
| Inline | `inline` |
| Loose | `loose` |
