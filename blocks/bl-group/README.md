# bl-group

Custom **carousel** block. Purpose: category-story-carousel.

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: head row (heading + View more link), then one row per card: image | linked title + description (+ optional tag links).
